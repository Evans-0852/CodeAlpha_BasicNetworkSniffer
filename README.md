# Basic Network Sniffer

## Description

This project is a basic network packet sniffer developed in Python using the Scapy library.

The program captures network packets from a network interface and displays useful information about the traffic, including source IP address, destination IP address, protocol, and packet information.

This project was developed as part of the CodeAlpha Cyber Security Internship.

## Features

- Captures network packets
- Displays source IP addresses
- Displays destination IP addresses
- Identifies network protocols
- Displays packet information
- Uses Scapy for packet capture and analysis

## Technologies Used

- Python 3
- Scapy
- Linux

## Requirements

- Python 3
- Scapy
- A Linux system
- Root/sudo privileges for packet capture
